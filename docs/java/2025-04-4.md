
# Nested Classes

```java
class A {
	class B {
	}
}
```


### Creating new Instance
```java
A.B  b = new A().new B();
```
or
```java
A a = new A();
A.B b = a.new B();
```

### Members
```java
class A {
	int a = 0;
	static int a2 = 10;
	A() {
		System.out.println("A");
		a = 1;
	}
	
	class B {
		B() {
			System.out.println("B");
		}
		
		void m1() {
			// we can access memebers to A from within B
			System.out.println(a);
			System.out.println(a2);
		}
	}
}
```
However
```java
class A {
	int a = 0;
	static int a2 = 10;
	A() {
		System.out.println("A");
		// this will give us an error, since we need an object of B;
		// System.out.println(B.b);
		//
		// So if we create an object of B
		System.out.println(new B().b);
		
	}
	
	class B {
		int b = 10;
	}
}
```
